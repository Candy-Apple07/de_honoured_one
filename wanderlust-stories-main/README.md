A modern and responsive travel blog website built to share travel stories, destinations, and experiences with a clean UI and smooth browsing experience.

✨ Features

Fully responsive design 📱💻

Clean and modern travel blog UI ✨

Blog-style layout for travel stories and destinations 🗺️

Fast performance using Vite ⚡

Smooth navigation and structured layout

🛠 Tech Stack Used

React

Vite

Tailwind CSS

JavaScript / TypeScript

🚀 Getting Started (Local Setup)

To run this project locally:

npm install
npm run dev
